# Reference-video analysis schema

Produce a compact Markdown or JSON analysis with these sections.

## Source

- URL/file, creator/title, acquisition method, duration, dimensions, fps, codecs.
- User-requested duration, aspect ratio, language, model, and fidelity.

## Global treatment

- Genre and objective.
- Color, lighting, texture, camera language, edit rhythm, and audio character.
- Persistent layout zones: top brand, center promotional copy, lower subtitles, bottom CTA.

## Timeline table

For every shot or meaningful overlay change, record:

| Time | Visual subject | Framing/movement | Transition/speed | Text | Audio | Source |
|---|---|---|---|---|---|---|

Use exact timecodes when possible. Mark estimates with `~`.

## Copy and audio

- Narration transcript with confidence notes.
- Speaker style, speed, emphasis, pauses, and language.
- Music, ambience, effects, and mix hierarchy.
- Separate “original mix” from “isolated voice”; do not conflate them.

## Reconstruction plan

- Seedance-generated visual components.
- Authentic supplemental footage and source/license.
- Post-production elements: exact typography, logos, prices, schedules, QR codes, subtitles.
- Risks: identity, voice authorization, copyrighted music/footage, unreadable text, model artifacts.
